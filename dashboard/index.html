How “separated” were ecosystems long ago?

Simple summary (ELI10):

  • We split the map into squares, then check which squares share the same genera.
  • High score = regions look different from each other (more “separate”).
  • Low score = regions look similar (more “mixed together”).

What this score really is: a network “clumpiness” number (modularity) built from locality ↔ genus links. It uses paleocoordinates when available (otherwise modern coordinates), with 5°×5° bins. It’s a helpful proxy, but it can also be influenced by sampling and climate.

Is this just random?

Simple summary (ELI10):

  • We keep the same number of fossils per place and per genus…
  • …but shuffle which genus goes with which place.
  • If the real score is much higher than the shuffled scores, the pattern is likely real.

🚀 Future Analysis Ideas

  • Bayesian Diversification Rates (PyRate): Use full MCMC to estimate origination/extinction rates with proper uncertainty intervals (requires significant compute).
  • Paleo-Coordinates Animation: Animate the movement of continents and fossil occurrences over 500 million years using GPlates API.
  • Morphometric Analysis: If trait data (body size, shape) is available, analyze the evolution of body forms (e.g., Cope's Rule).
  • Community Detection: Use advanced network clustering to identify "bioregions" automatically and track how they merge/split.
  • Preservation Bias Correction: Implement sophisticated sampling standardization (e.g., TRiPS) to correct for the "Pull of the Recent".
