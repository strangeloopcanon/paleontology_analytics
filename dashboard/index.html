How provincial was the ancient world?

We used Network Theory to measure biogeographic provinciality—how strongly fossil communities split into distinct regional clusters.

What this score is: network modularity of a locality–genus co-occurrence graph built in paleocoordinate space when available (otherwise modern coordinates), using 5°×5° spatial bins.

How to read it: Higher modularity = stronger regional differentiation; lower modularity = more homogenized assemblages. Continental configuration can influence this, but so can climate, sampling intensity, and the binning/model choices—so treat it as a proxy, not a direct “Pangaea dial”.

Is this pattern real?

We ran a Null Model Test on a well-sampled time bin: shuffle genus labels across locality–genus edges (preserving the number of occurrences per locality and overall genus frequencies), then recompute modularity. If the observed value is far into the tail, the structure is unlikely to be explained by random mixing alone.

Can AI predict who survives?

We trained a Random Forest to predict whether a genus disappears in the next time bin, using simple features computed from occurrences: geographic spread, abundance, latitudinal range, and “age” (bins observed).

Important: This is a toy model on a sampled dataset; the metrics shown are on a held‑out test split. It’s meant to be exploratory, not a causal claim.

🚀 Future Analysis Ideas

  • Bayesian Diversification Rates (PyRate): Use full MCMC to estimate origination/extinction rates with proper uncertainty intervals (requires significant compute).
  • Paleo-Coordinates Animation: Animate the movement of continents and fossil occurrences over 500 million years using GPlates API.
  • Morphometric Analysis: If trait data (body size, shape) is available, analyze the evolution of body forms (e.g., Cope's Rule).
  • Community Detection: Use advanced network clustering to identify "bioregions" automatically and track how they merge/split.
  • Preservation Bias Correction: Implement sophisticated sampling standardization (e.g., TRiPS) to correct for the "Pull of the Recent".
